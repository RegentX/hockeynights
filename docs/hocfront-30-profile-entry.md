# HOCFRONT-30 — Профиль в шапке и краткая карточка Hockey ID

## Задача

Сделать вход в профиль «как во ВКонтакте»:

1. В верхнем навбаре — ФИО игрока и кнопка перехода в профиль.
2. На странице профиля — краткая информация и кнопка «Подробнее» для полной анкеты.

## Что сделано

### Верхний навбар

- Новый виджет `widgets/HeaderProfile` в `app-shell__header-actions`:
  - круглый аватар с инициалами (`ИП` для «Иван Петров»);
  - ФИО из `GET /profile/me`, фолбэк — `session.user.displayName`;
  - подпись «Амплуа · Уровень» (для партнёрских аккаунтов — «Кабинет партнёра»);
  - кнопка «В профиль».
- Ссылка ведёт на `/profile`, для партнёрского workspace — на его основной кабинет
  (`getPrimaryPartnerPath`), потому что `/profile` для таких аккаунтов редиректит.
- Профиль подгружается только вне партнёрского workspace (`enabled` у query).
- Адаптив: до 768px остаётся только аватар, кнопка «В профиль» показывается с 1200px
  (на мобиле вход в профиль уже есть в bottom nav).

### Страница профиля

- Новый компонент `features/profile/ui/ProfileSummaryCard` — краткая инфа:
  ФИО, «Hockey ID», амплуа · уровень, локация (`город · район · м. метро`),
  статус верификации, бейджи ролей, короткое био (до 160 символов),
  заполненность профиля и карма.
- Кнопка «Подробнее» / «Свернуть» раскрывает панель «Hockey ID · подробно»
  (`aria-expanded` + `aria-controls`): панель тренера, панель вратаря, ачивки,
  поля анкеты, история участия, «Подтвердить профиль» / «Сохранить профиль».
- Кнопка «Публичный вид» ведёт на `/players/:userId` — как профиль видят другие.
- Дубли убраны: заполненность и карма живут в краткой карточке, в подробной панели
  остался только `KarmaHint`; `ProfileRoleBadges` переехали в `features/profile`.

### Общее

- `shared/lib/profileIdentity.ts`: `getProfileInitials`, `formatProfileLocation`.
- Стили: `app-shell__profile*` в `_layout.scss`, `profile-summary*` в `_profile.scss`.

## Тест-план

- `npm run test` — 173 теста, включая `src/test/hocfront-30-profile-entry.spec.tsx`:
  - шапка: ФИО, инициалы, `href=/profile` у identity-ссылки и кнопки, подпись «Нападение · Любитель»;
  - профиль: краткая карточка без полей анкеты, раскрытие по «Подробнее» (`aria-expanded`),
    поле «ФИО» и история участия внутри панели, повторный клик сворачивает;
  - `getProfileInitials` на пустой строке и множественных пробелах.
- `npm run lint`, `npm run typecheck`, `npm run build` — зелёные.
- Ручная проверка в браузере: desktop (ФИО + кнопка в шапке, раскрытие/сворачивание)
  и mobile 390×844 (в шапке только аватар, вёрстка не ломается).
