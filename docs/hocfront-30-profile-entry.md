# HOCFRONT-30 — Профиль в шапке и краткая карточка Hockey ID

## Задача

Сделать вход в профиль «как во ВКонтакте»:

1. В верхнем навбаре — ФИО игрока и кнопка перехода в профиль.
2. На странице профиля — краткая информация и кнопка «Подробнее» для полной анкеты.

## Что сделано

### Верхний навбар (правый угол, ВК-стиль)

- Новый виджет `widgets/HeaderProfile` — последний элемент `app-shell__header-actions`,
  занял место кнопки «⋯» из HOCFRONT-17:
  - круглый аватар с инициалами (`ИП` для «Иван Петров») и Lottie-кольцо вокруг него
    (`shared/assets/lottie/profile-ring.json`: пунктирное вращающееся кольцо + пульс);
  - ФИО из `GET /profile/me`, фолбэк — `session.user.displayName`;
  - подпись «Амплуа · Уровень» (для партнёрских аккаунтов — «Кабинет партнёра»);
  - текстовой кнопки «В профиль» нет — вход в профиль живёт в меню аватара.
- Клик по аватару открывает меню: «Мой профиль», «Как видят другие» и пункты сессии
  из AppShell («Сменить роль», «Фокус на чат» на `/messenger`, «Выйти»).
- Профиль ведёт на `/profile`, для партнёрского workspace — на его основной кабинет
  (`getPrimaryPartnerPath`), потому что `/profile` для таких аккаунтов редиректит.
  Профиль подгружается только вне партнёрского workspace (`enabled` у query).
- Анимация кольца: одно проигрывание после загрузки, затем по hover/фокусу и пока меню
  открыто; при `prefers-reduced-motion: reduce` — статичный кадр.
- Адаптив: до 1200px остаются только аватар и меню (ФИО и подпись скрыты),
  на мобиле вход в профиль дополнительно есть в bottom nav.

### Объединение с HOCFRONT-17 (PR-41)

- Ветка вобрала `feature/HOCFRONT-17` и актуальный `develop`; конфликты решены так:
  - `deploy.yml` — оставлен двухшаговый audit из HOCFRONT-17 (runtime как гейт,
    полный как advisory);
  - `package.json` / `package-lock.json` — overrides из develop (`postcss 8.5.24`,
    `brace-expansion`, minimatch-пины) плюс `lottie-react` из HOCFRONT-17;
  - `AppShell` — компактный top bar HOCFRONT-17 (колокольчик, icon-кнопки темы и панелей)
    и профиль HOCFRONT-30 вместо «⋯»; `sessionMenuItems` переехали в меню профиля.
- `usePrefersReducedMotion` вынесен из `NotificationsBellLink` в
  `shared/lib/usePrefersReducedMotion.ts` и переиспользуется колокольчиком и профилем.

### Страница профиля

- Новый компонент `features/profile/ui/ProfileSummaryCard` — краткая инфа:
  ФИО, «Hockey ID», амплуа · уровень, локация (город),
  статус верификации, бейджи ролей, короткое био (до 160 символов),
  заполненность профиля и карма.
- Кнопка «Подробнее» / «Свернуть» раскрывает панель «Hockey ID · подробно»
  (`aria-expanded` + `aria-controls`): панель тренера, панель вратаря, ачивки,
  поля анкеты, история участия, «Подтвердить профиль» / «Сохранить профиль».
- Кнопка «Публичный вид» ведёт на `/players/:userId` — как профиль видят другие.
- Дубли убраны: заполненность и карма живут в краткой карточке, в подробной панели
  остался только `KarmaHint`; `ProfileRoleBadges` переехали в `features/profile`.

### Общее

- `shared/lib/profileIdentity.ts`: `getProfileInitials`, `formatProfileLocation`.
- Стили: `app-shell__profile*` в `_layout.scss`, `profile-summary*` в `_profile.scss`.

- Ручная проверка в браузере: desktop (профиль в правом углу, меню аватара, раскрытие

  вёрстка не ломается, «⋯» отсутствует), консоль без ошибок Lottie.
