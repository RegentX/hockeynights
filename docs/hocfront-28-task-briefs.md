## HOCFRONT-28A — Новая информационная архитектура `/events`

| | |
|---|---|
| **Приоритет** | P0 |
| **Владелец** | FE |
| **Зависимости** | нет |
| **Статус** | done |

### Цель

Сделать каталог игрока первым экраном: поиск и запись. Создание и кабинет организатора — отдельные entry points, не блоки в середине ленты.

### Scope

1. Убрать inline `EventCreateForm` и `OrganizerTrainingsPanel` из основного потока `/events`.
2. В шапке раздела (для `canOrganizeEvents`) показать компактные кнопки:
   - «Создать» → `/events/create`
   - «Мои тренировки» → `/events/organizer`
3. Добавить маршруты и страницы-обёртки:
   - `/events/create` — форма создания
   - `/events/organizer` — кабинет организатора
4. Заменить вкладки каталога на:
   - **Для меня** — будущие доступные события, отсортированные «ближе по времени» (MVP без ML)
   - **Тренировки**
   - **Игры**
   - **Мои записи** — события, где у текущего пользователя `going` или `maybe` (waitlist)
5. Сохранить deep-link на карточку (`#eventId`) и back с деталки на `/events`.
6. League RSVP оставить вторичным и свёрнутым.

### Out of scope

- redesign `EventCard` (28B);
- chips / URL-фильтры (28C);
- sticky CTA / trust на деталке (28D);
- отдельная registration state machine (28E).

### Acceptance

- [x] На `/events` нет формы создания и списка «Кабинет организатора» в основном потоке
- [x] Организатор видит кнопки «Создать» / «Мои тренировки»
- [x] `/events/create` и `/events/organizer` открываются и работают
- [x] Вкладки: Для меня / Тренировки / Игры / Мои записи
- [x] «Мои записи» показывает только события с записью пользователя
- [x] Тесты обновлены; typecheck green

## HOCFRONT-28B — Карточка события v2

| | |
|---|---|
| **Приоритет** | P0 |
| **Владелец** | FE |
| **Зависимости** | 28A |
| **Статус** | done |

### Цель

Карточка отвечает «подходит ли мне?» без открытия деталки.

### Scope

- дата + день недели;
- длительность;
- цена в `₽` (не `RUB`);
- свободные места всего и по позиции пользователя (если известна);
- статус записи пользователя;
- арена / район;
- один главный CTA (Записаться / В лист ожидания / Вы записаны).

### Acceptance

- [x] Карточка показывает дату, ₽, арену, уровень, места
- [x] CTA соответствует статусу
- [x] Нет технических терминов `public_open` в UI (человеческие лейблы)

| **Владелец** | FE (+ BE2-015) |
| **Зависимости** | 28A |

### Цель
