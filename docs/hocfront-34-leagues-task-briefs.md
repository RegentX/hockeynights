## Цель эпика

Сделать раздел **«Лиги»** продуктово цельным — без изменения уже сильной кабинетной части:

1. Публичный каталог с поиском/фильтрами (регион Москва/Россия, уровень, статус набора), единый термин в nav/заголовке/копирайте.
2. Тарифный флаг `paid/free` на кабинете лиги + mock paid gate (без реальной оплаты) — закрывает CEO TASK-07-03.
3. Демо-данные: региональное покрытие + связка с точкой расширения «клуб → лига» на будущее.
4. QA/polish: empty/error states, SRS-синхронизация spec-номеров, `hocfront-34-pr-summary.md`.

Порядок: **34A → 34B → 34C → 34D**.

## HOCFRONT-34A — Каталог: поиск, фильтры, отдельная страница лиги, единый копирайт

| | |
|---|---|
| **Приоритет** | P0 |
| **Владелец** | FE |
| **Зависимости** | нет |
| **Статус** | **done** |

### Цель

Дать пользователю найти лигу так же удобно, как арену: список, живой поиск, фильтр вместо одного скролла из трёх карточек. По ходу реализации скоуп расширен до полноценной страницы `/leagues/:leagueId` (по аналогии с `/arenas/:arenaId`) — inline-панель в каталоге больше не единственный способ посмотреть лигу, что также устранило визуальный разнобой ♥/бейджа «Профиль лиги» на карточке.

### Scope

1. ~~Поле поиска по названию + фильтр **регион**~~ Поле поиска по названию + фильтр **регион**: `Москва` | `Россия` (остальные регионы) | все — по аналогии с фильтром города в `/arenas`. **Реализовано** (`LeagueFilters`, `resolveLeagueRegion`).
2. Фильтр **уровень** (`SkillLevel`) и **статус набора** (`recruitingStatus: open/waitlist/closed`). **Реализовано.**
3. URL-состояние фильтров (`q`, `region`, `level`, `recruitingStatus`) + отдельный маршрут `leagueId` для деталки (не query-параметр, как изначально планировалось, а полноценный `/leagues/:leagueId`, как у арен). **Реализовано** (`LeagueDetailsPage`, `leagueDetailsPath`), легаси `?leagueId=` редиректит на новый маршрут.
4. Единый термин **«Лиги»**: `LEAGUES_LABEL`/`LEAGUES_PAGE_TITLE` в `navigationLabels.ts`, убраны расхождения «Любительские лиги» / «Каталог лиг» в `navigationAccess.ts`. **Реализовано.**
5. Empty state («лиг по фильтру не найдено») + error state запроса. **Реализовано.**
6. Design-фикс: ♥ избранного и бейдж «Профиль лиги» выровнены в общий чип-ряд `.league-meta-chips`/`.league-meta-chip` (аналог `.arena-meta-chip`) — раньше `favorite-btn` (32×32, квадрат) и `entity-profile-badge` (26px pill) стояли рядом без общего контейнера. **Реализовано** в `LeagueCard` и `LeagueProfilePanel`.
7. Виджет **«Моя лига»** (`MyLeagueWidget`) на каталоге: место в таблице + ближайший матч для игрока, чья команда привязана к лиге (`Team.leagueId`, уже был в модели — см. правку 34C). **Реализовано.**

### Out of scope

- сама структура карточки/панели профиля — не трогаем;
- кабинет партнёра.

### Acceptance

- [x] Поиск по названию фильтрует список
- [x] Фильтр региона Москва/Россия/все меняет выдачу
- [x] `/leagues/league-002` открывает отдельную страницу лиги; `/leagues?leagueId=league-002` редиректит туда же
- [x] Единый термин в nav/title/копирайте
- [x] Тесты: фильтр региона, поиск, deep-link редирект, empty state, виджет «Моя лига» (`hocfront-34-leagues.spec.tsx`)
