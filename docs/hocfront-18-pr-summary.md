## Summary

Единый display-тон для названий сущностей (Bebas / `header-2`, эталон — «Ледовый дворец на Ходынке») и фикс layout в focus-режиме без боковых панелей.

## Что сделано

### Типографика карточек / списков
- Названия сущностей переведены с `subheader-2` (scoreboard mono) на `header-2` (Bebas Neue):
  - арены (`RinkCard`)
  - события (`EventCard`)
  - лиги (`LeagueCard`)
  - магазины (`ShopCard`)
  - игроки (`PlayerCard`)
  - моменты (`HighlightCard`)
- В `index.scss` для `header-2` зафиксированы размер, letter-spacing и uppercase — тот же визуальный ряд, что у заголовка детали арены.

### Layout (focus / свёрнутые панели)
- При скрытых left + right панелях у `.app-shell__main-col` больше не `padding: 0` — контент не липнет к краям экрана.
- Добавлены горизонтальные gutters (`clamp(20px, 4vw, 48px)`), `max-width: 1400px`, центрирование.
- Header в том же режиме получает согласованные `padding-inline`.
- Разделитель «Требует доработки» в side nav — по центру, линии слева и справа.

## Out of scope / откат
Агрессивный type-ramp (`_typography.scss`, Inter на card titles, глобальные `!important`) **не вошёл** — ломал фирменный display-шрифт; оставлен минимальный безопасный путь через Gravity `header-2`.
